# 快捷栏系统 — 设计规范

## 架构

```
ItemData (.tres 静态数据)
    ↓
QuickBarManager (autoload) — 9格数组 + 信号
    ↓
QuickSlotUI + QuickBarUI — 渲染 + 交互
```

## QuickBarManager 接口

**信号：** `quickbar_changed`

**数据：** `quickbar: Array[9]`，每格存 `ItemData` 或 `null`

| 方法 | 触发方式 | 行为 |
|------|---------|------|
| `set_slot(index, item)` | 拖拽放入 | 覆盖写入，发信号 |
| `use_slot(index)` | 数字键 1-9 | 在背包中找到该物品 → 调用 `InventoryManager.equip()`；找不到则静默跳过 |
| `clear_slot(index)` | 右键 / 拖出格子 | 清空为 null，发信号 |

## 交互决策

| 决策点 | 结论 |
|--------|------|
| 存的是引用还是副本 | 引用，本体在 `InventoryManager.backpack` |
| 装备后快捷栏状态 | 保留不清空 |
| 物品已装备再按数字键 | 背包中无该物品，静默跳过（不卸下） |
| 消耗品使用后 | 保留在格子里（除非物品消耗后从背包移除） |
| 拖拽到已有物品格 | 直接覆盖 |
| 物品彻底离开背包时 | 快捷栏需要反应（后续处理） |

## 快捷栏格子清空

- **右键**：`_gui_input` 中 `MOUSE_BUTTON_RIGHT` → `QuickBarManager.clear_slot(index)`
- **拖出格子外**：`_notification(NOTIFICATION_DRAG_END)` → 暂缓实现

## QuickBarManager 伪代码

```gdscript
extends Node
signal quickbar_changed
const SIZE := 9
var quickbar: Array = []

func _ready():
    quickbar.resize(SIZE)

func set_slot(index, item):
    quickbar[index] = item
    quickbar_changed.emit()

func clear_slot(index):
    set_slot(index, null)

func use_slot(index):
    var item = quickbar[index]
    if item == null: return
    # 在背包中找该物品
    for i in InventoryManager.BACKPACK_SIZE:
        if InventoryManager.backpack[i] == item:
            InventoryManager.equip(i)
            return
```
