# 计划：角色装备武器显示（土豆兄弟风格）

## Context

玩家已能通过 InventoryManager 装备武器（写入 `equipment["weapon"]`），但角色身上没有任何视觉反馈。目标是让装备后的武器出现在角色身旁，跟随移动方向旋转，为后续按键攻击打好基础。攻击方向不用鼠标，由移动方向决定。

---

## 当前状态

**player.tscn 节点树：**
```
Player (CharacterBody2D)
├── CollisionShape2D
├── Camera2D
└── AnimatedSprite2D
```

**player.gd**：只有移动和动画，没有监听装备信号。

**InventoryManager**：`equipment["weapon"]` 存当前装备，装备变化时发出 `equipment_changed` 信号。

**ItemData**：有 `icon: Texture2D` 属性，武器图标从这里取。

---

## 实现方案

### 第一步：在 player.tscn 添加武器节点

在 Player 下添加：
```
Player
├── ...（已有节点）
└── WeaponPivot (Node2D)   ← 旋转轴心，position = (0, 0)
    └── WeaponSprite (Sprite2D)  ← 武器图标，position = (14, 0)，初始隐藏
```

**WeaponPivot**：绕角色中心旋转，移动时转动这个节点让武器跟着转向。  
**WeaponSprite**：向右偏移 x=14px（约半个角色宽），武器图标显示在这里。

> 为什么用 Node2D + Sprite2D 而不是直接加 Sprite2D？Pivot 是旋转轴心，武器的偏移和旋转逻辑完全解耦，后续加挥击动画只需对 Pivot 做 Tween 旋转。

---

### 第二步：修改 player.gd

**改动 1** — `_ready()` 里连接信号并初始化武器显示：
```gdscript
InventoryManager.equipment_changed.connect(_on_equipment_changed)
_on_equipment_changed()
```

**改动 2** — `_physics_process()` 里武器跟随移动方向旋转（静止时保持上次方向）：
```gdscript
# direction 已有，复用即可
if direction.length_squared() > 0.01:
    $WeaponPivot.rotation = direction.angle()
# 武器朝左时垂直翻转，避免图标上下颠倒
$WeaponPivot/WeaponSprite.flip_v = abs($WeaponPivot.rotation) > PI / 2.0
```

**改动 3** — 新增 `_on_equipment_changed()` 方法：
```gdscript
func _on_equipment_changed() -> void:
    var weapon := InventoryManager.equipment["weapon"] as ItemData
    var sprite := $WeaponPivot/WeaponSprite as Sprite2D
    if weapon == null:
        sprite.visible = false
        sprite.texture = null
    else:
        sprite.texture = weapon.icon
        sprite.visible = true
```

---

## 涉及文件

| 文件 | 改动类型 |
|------|---------|
| `scenes/player.tscn` | 添加 WeaponPivot + WeaponSprite 节点（MCP 操作） |
| `scripts/player.gd` | 添加信号连接 + 旋转逻辑 + `_on_equipment_changed` |

---

## 验证步骤

1. 运行游戏
2. 打开背包（B），双击矿稿装备到武器槽
3. 角色旁边出现矿稿图标，默认朝右
4. 按 A/D/W/S 移动，图标跟随移动方向旋转
5. 松开方向键静止，图标保持最后朝向不动
6. 向左走时图标不会上下颠倒（flip_v 生效）
7. 双击卸下武器，图标消失
